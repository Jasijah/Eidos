# Beta User Guide

## First session

1. Install and open Eidos.
2. Choose the meeting type you attend most.
3. Review the real-voice and local-first explanations.
4. Open Privacy Dashboard and allow local image processing.
5. Upload front, left profile, and right profile photos in Avatar Studio.
6. Generate the local avatar identity and complete the walkthrough.
7. Connect the real microphone.
8. Optionally complete 60-second camera training. The camera turns off afterward.
9. Run System Check.
10. Start a practice session in Live Presence.

## Join a real meeting

1. Open Virtual Camera Setup and choose resolution, frame rate, background, and disclosure.
2. Open the dedicated Eidos output window.
3. In OBS, add Window Capture for `Eidos Avatar Output` and fit it to the canvas.
4. Start OBS Virtual Camera.
5. In Zoom, Meet, Teams, or Discord, select OBS Virtual Camera and keep the real microphone selected.

## Support

Export System Check diagnostics and email `support@eidospresence.com`. Never include private meeting audio or video.
