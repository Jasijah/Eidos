# Investor Metrics

The Founder Dashboard summarizes closed beta users, WAU, onboarding completion, avatar creation, voice-only adoption, presence quality, NPS proxy, willingness to pay, feature requests, bugs, and beta health.

For external reporting, use cohort-based metrics and disclose the sample size. Avoid presenting local leads as active users, model naturalness as user satisfaction, referral codes as referrals before acceptance, or unsigned installer downloads as retained usage.

The strongest early narrative is repeated camera-free sessions with authentic voice, high trust, and a concentrated very-disappointed segment. Report weekly retention, session frequency, voice-only share, PMF response, trust, and paid-pilot interest together.
