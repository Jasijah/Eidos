# Eidos 0.1.0-beta Release Notes

## Added

- Personalized first-run onboarding based on meeting type.
- Trust Center with plain-language voice, privacy, image, encryption, consent, export, and deletion policies.
- Interactive post-avatar Presence walkthrough and practice path.
- System Check with green/yellow/red results and diagnostic export.
- Help Center, quick start, FAQ, troubleshooting path, and Beta Hub.
- Expanded Founder Dashboard for DAU, WAU, retention, invite conversion, feedback completion, timing, bugs, requests, and quality trends.
- Branded desktop icon and splash screen.
- Keyboard skip link, visible focus treatment, scalable layout, and reduced-motion support.
- Friendly recovery actions with retry, diagnostics, and support links.

## Unchanged policy

Eidos uses the user's real microphone audio. It does not clone voices, generate speech, or speak for the user.
