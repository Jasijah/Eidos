# Administrator Console Guide

Enable Developer Mode from Beta Dashboard, then open Administrator Console. The console reads local beta intelligence and never uploads it automatically.

Use **Provision 3 invites** to create the founder referral set. Invite records include creator, cohort, expiration, maximum uses, and accepted uses. Export analytics and feedback as JSON; export invites and beta signup leads as CSV. Combine exports only in a controlled analysis workspace because signup leads contain personal information while analytics are anonymous.

Review Founder Dashboard before the raw console. Use the console to investigate denominator issues, cohort differences, crashes, feature adoption, and specific feedback themes. Do not treat unaccepted invites or signup leads as active users.
