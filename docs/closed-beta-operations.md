# Closed Beta Operations

Beta enrollment is local and uses a cohort code, consent version, platform, primary use case, and an optional diagnostics-export flag. No enrollment data is uploaded automatically. Participants explicitly export anonymized ratings or diagnostic JSON for support.

Start with 10-20 users. Require signed installers, consent versioning, a support contact, incident response, deletion instructions, and a test matrix. Review realism, naturalness, trust, comfort, usefulness, session-start reliability, GPU class, call platform, and willingness to pay weekly.
