# Beta User Testing Plan

## Cohort

Begin with 10-20 consented users across professional calls, creator sessions, low-energy/sick-day use, and camera-comfort use cases. Do not use uploaded photos or raw media for model training.

## Session

1. Complete photo onboarding and the 60-second behavior training flow.
2. Join one controlled OBS-routed call and one normal work call.
3. Test camera-tracked and voice-only presence.
4. Rate realism, naturalness, trust, usefulness, comfort, and willingness to pay from 1-5.
5. Export anonymized feedback JSON only when the participant chooses to share it.

## Gates

Closed-beta targets: naturalness >= 3.8, trust >= 4.0, comfort >= 4.0, no critical privacy incidents, and less than 2% failed session starts. Record GPU/OS/browser separately from anonymized product feedback.
