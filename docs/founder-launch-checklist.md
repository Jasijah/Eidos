# Founder Launch Checklist

## Before invitations

- [ ] Create signed Windows installer and notarized macOS build when credentials are available.
- [ ] Test installation and uninstall on clean machines.
- [ ] Verify onboarding, avatar creation, training, practice, OBS routing, feedback, and invites end to end.
- [ ] Complete privacy, biometric, security, and commercial-license reviews.
- [ ] Configure support inbox, response owner, Discord, and escalation policy.
- [ ] Publish release notes, known issues, user guide, and download checksums.
- [ ] Generate 20 cohort-scoped invitations.

## Daily during beta

- [ ] Review crashes and diagnostics.
- [ ] Track installs, onboarding, avatar creation, meetings, repeat use, trust, naturalness, and willingness to pay.
- [ ] Respond to red system checks and blocked users within one business day.
- [ ] Maintain a ranked bug and feature-request list.
