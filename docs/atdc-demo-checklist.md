# ATDC Demo Checklist

- [ ] Confirm desktop build and OBS scene before the session.
- [ ] Use a locally generated avatar with explicit image consent.
- [ ] Complete System Check and save the diagnostic result.
- [ ] Demonstrate authentic live microphone audio and camera-off presence.
- [ ] Show training maturity, universal/user profile blending, and anti-uncanny safeguards.
- [ ] Show Trust Center, local encryption, data export, and delete everything.
- [ ] Present the beta funnel and success definition for 20 invited users.
- [ ] Ask for feedback on enterprise trust, accessibility, distribution, and buyer profile.
