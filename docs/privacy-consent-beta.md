# Privacy and Consent Beta

Beta defaults are local-only mode, no public training, no cloud upload, no third-party avatar generation, and no raw media retention.

Privacy Dashboard controls image processing, local avatar storage, local behavior storage, normalized-record model improvement, third-party avatar processing, export, and deletion.

Avatar identity and behavior memory have separate deletion controls. Users can delete retained source images while keeping the generated avatar profile, delete the avatar profile, delete behavior memory, or delete everything.

The user's real voice is used directly. Audio is not stored and voice cloning is not implemented. Training camera frames are processed in memory. Only summarized behavior profiles may be stored locally.
